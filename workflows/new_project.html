Introduction

This workflow should be used when creating a new project and merging it with the most recent disturbance database. Steps include:

  1. Prepare project geopackage and backup the existing disturbance database
  2. Use the new project AOI to select all intersecting 10-km grid cells
  3. Use the selected grid cells to clip all existing linear and areal features
  4. Digitize new features, remove features no longer visible, and modify erroneous features
  5. Erase all linear and areal features within the AOI-GRID from the existing disturbance database
  6. Replace AOI-GRID gap with the newly modified linear and areal disturbance features
  7. Replace the original disturbance database with the updated version

Step 1: Backup existing disturbance database

Prepare the project geopackage by creating a new project folder and copying your AOI map layer into it. Also, make sure to backup or archive the existing disturbance database (disturbances.gpkg) e.g., disturbances_2026-08-13.gpkg

Step 2: Select intersecting grid cells

Use the AOI to select all intersecting 10x10 km grid cells.

Code 
aoi_grid <- grid[st_intersects(grid, aoi, sparse = FALSE)[, 1], ]
st_write(aoi_grid, project_gpkg, layer = "aoi_grid", delete_layer = TRUE, quiet = TRUE)
tm_shape(grid, bbox = map_bbox) + tm_borders(col = "grey50") +
  tm_shape(aoi_grid) + tm_polygons(fill = "grey70", col = "grey50") +
  tm_shape(aoi) + tm_borders(col = "black", lwd = 2) +
  tm_title("Selected AO grid cells")

Step 4: Digitize

Use QGIS to digitize new features, remove features no longer visible, and modify erroneous features. Make sure the entire area of the aoi_grid is reviewed and updated.

Erase all linear and areal features within the AOI-GRID from the existing disturbance database
